# 1. Introduction

This section is written as a skeleton (context, literature, problem, objectives) because
the full introduction is finalised once results are available. It is intentionally
explicit about what each paragraph will cover.

**Context and background.** Establish the current landscape of digital education in
applied fields such as Information Technology at the Durban University of Technology,
focusing on the reliance on traditional 2D materials.

**Literature and gaps.** Review current XR adoption in higher education, identifying key
limitations such as system latency, small single-institution sample sizes, and unverified
theoretical knowledge retention.

**Problem and motivation.** Justify the need for a standardised, multi-attribute
framework that connects real-time student engagement with long-term retention tracking.

**Proposed solution.** This study proposes the Scalable, Evidence-Based XR Integration
Framework (SEB-XRIF). It addresses the retention and scalability gaps above, adopts the
Design Science Research Methodology (DSRM), uses the public xAPI Educational Mining
Dataset (480 records, 17 attributes) acquired from Kaggle, builds on a Python, Flask,
React.js, and Scikit-learn stack with a Random Forest Classifier, and evaluates with
F1-score, the System Usability Scale, and Cohen's d effect size.

## 1.2 Objectives

1. Review existing immersive pedagogical methods to pinpoint structural barriers
   preventing effective theoretical knowledge transfer.
2. Define a standardised framework architecture for XR assessment that accommodates
   longitudinal data gathering and multi-institutional adoption.
3. Build an interactive analytics dashboard prototype using the xAPI dataset to display
   participation trends and forecast student performance.
4. Assess framework usability and efficacy using the System Usability Scale (SUS) and
   Cohen's d effect size calculations.
