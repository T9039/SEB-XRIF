# 1. Introduction

**Context and background.** Digital education in applied fields such as
Information Technology at the Durban University of Technology still relies
heavily on traditional two-dimensional materials, which limits the immersive,
practice-oriented learning that the discipline increasingly demands.

**Literature and gaps.** Current Extended Reality (XR) adoption in higher
education shows strong immediate engagement but key limitations: system latency,
small single-institution sample sizes, and theoretical knowledge retention that
is rarely verified. The group systematic literature review of 28 studies found a
median cohort of 30 and almost no delayed retention measurement.

**Problem and motivation.** There is a need for a standardised, multi-attribute
framework that connects real-time student engagement with long-term retention
tracking, so that individual pilots accumulate into comparable evidence rather
than remaining isolated.

**Proposed solution.** This study proposes the Scalable, Evidence-Based XR
Integration Framework (SEB-XRIF). It addresses the retention and scalability gaps
above, adopts the Design Science Research Methodology (DSRM) across its six
phases from problem identification to communication, uses the public xAPI
Educational Mining Dataset (480 records, 16 predictors plus a class label)
acquired from Kaggle, builds on a Python, FastAPI, React, and scikit-learn stack
with a Random Forest Classifier, and evaluates with F1-score, the System
Usability Scale, and Cohen's d effect size.

## 1.2 Objectives

1. Review existing immersive pedagogical methods to pinpoint structural barriers
   preventing effective theoretical knowledge transfer.
2. Define a standardised framework architecture for XR assessment that accommodates
   longitudinal data gathering and multi-institutional adoption.
3. Build an interactive analytics dashboard prototype using the xAPI dataset to display
   participation trends and forecast student performance.
4. Assess framework usability and efficacy using the System Usability Scale (SUS) and
   Cohen's d effect size calculations.
